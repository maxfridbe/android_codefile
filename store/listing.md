# CodeFile

Short description:
Read code natively with syntax colors, diffs, Markdown, JSON trees and PDF sharing.

Full description:
CodeFile is a native Android viewer for source code and text. Open files from your device or share text from another app. Read with syntax highlighting, line numbers, search, themes, touch zoom and wrapping.

Use the contextual Markdown ribbon to preview headings, lists, code blocks, tables and task lists. Explore JSON objects and arrays in an expandable tree without changing numeric values. Built-in formatting handles common code and data formats, including YAML, CSV and XML.

See YAML, TOML, INI, properties, XML and JSON Lines as expandable trees, and read .diff patches with colored changes. Choose A4, Letter, A5 or another paper size when you share a syntax-highlighted PDF, or cast the viewer to a TV. Compare documents with visual diffs. Select text or drag line numbers to select whole lines, apply highlight colors, copy snippets, or share a styled PDF. Local navigation includes searchable symbols and previews. Java navigation works within the open file; other languages use a local lexical index.

The ribbon adapts to phones, tablets and foldable screens. Settings include paired light and dark themes and embedded Nerd Fonts.

Open code straight from the clipboard and let CodeFile guess the language, which you can change at any time. Open a public GitHub file straight from its link, then save a local copy or share it as a file attachment. Local viewing and formatting work without a network connection. Optional AI analysis sends only a snippet you preview and explicitly submit to your chosen OpenRouter-compatible endpoint, including a local server. A third-party account or API key may be required by that provider.

No ads or tracking SDKs. No app account is required. Diagnostics stay local unless you choose to share a compressed log from Support.
